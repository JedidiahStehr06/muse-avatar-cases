# 静态图索引

本目录是静态图的文件名索引。图片本体在「Muse 形象定制案例库」空间中展示与下载；本仓库只存放文字与索引。

使用方法：挑一张静态图（或用自己的照片），连同 [cases.md](../cases.md) 里对应案例的“一键话术”一起发给你的 Muse，一句话搞定。动态图由 Muse 按静态图现场生成，不需要预先制作。
